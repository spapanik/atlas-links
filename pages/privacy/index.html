Atlas Links

Privacy policy

Atlas Links is a local-first bookmark manager. Your bookmarks stay on your device unless you explicitly enable private Google Drive sync.

Effective date: 16 July 2026

Overview

This policy explains what the Atlas Links Chrome extension processes, why it processes it, where the data is stored, and the choices available to you. Atlas Links has no developer-operated backend and does not sell personal information, serve advertising, or collect analytics or telemetry.

Data Atlas Links processes

  • Active page details: when you open Atlas Links to save a page, the extension reads the active tab's title and URL to pre-fill the bookmark form. It does not read your browsing history.
  • Bookmark data: URLs, names, descriptions, tags, stable identifiers, created and updated dates, and deletion markers needed to synchronize deletions.
  • Local application data: a random device identifier, data schema and revision information, sync state, and extension preferences such as appearance.
  • Imported and exported data: bookmark files you choose to import are processed locally. Exports are written to a file you choose to download.

Atlas Links does not collect Google passwords, payment information, health information, precise location, communications, or website content beyond the active page title and URL described above.

Local storage

Bookmark and application data is stored in Chrome's extension-local storage on your device. Local bookmark features work without an account and without sending bookmark data to Atlas Links' developer.

Local data remains until you delete it, clear the extension's data, or uninstall the extension. A deleted bookmark is represented by a minimal deletion marker so its deletion can synchronize. Atlas Links does not currently remove those markers automatically; they remain until the relevant extension or Drive application data is cleared.

Optional Google Drive sync

Google sign-in and sync are optional and begin only after an explicit action from you. Atlas Links uses Chrome's identity service for authentication and requests only this Google Drive permission: https://www.googleapis.com/auth/drive.appdata.

When sync is enabled, Atlas Links sends a versioned JSON copy of the bookmark store to Google's Drive API over HTTPS. It stores one file, named atlas-links.v1.json, in your private Google Drive application-data folder. The folder is hidden from the normal Drive file list and is intended for data used by Atlas Links, not access to your other Drive files.

Access tokens are obtained through Chrome's identity facilities and are used in memory for Google API requests. Atlas Links does not store or log those tokens itself. Signing out clears account-specific sync metadata and attempts to revoke cached authorization, but it keeps your local bookmarks. Signing out or uninstalling does not automatically delete the remote application-data file.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Data sharing and third parties

If you enable sync, bookmark data is shared with Google only to provide the backup and synchronization feature you requested. Google processes that data under the Google Privacy Policy. Atlas Links does not share bookmark data with advertisers, data brokers, analytics providers, or other third parties.

This policy page is hosted by GitHub Pages. Visiting the page may cause GitHub to process ordinary web request information under the GitHub Privacy Statement. The extension does not send your bookmarks to this website.

Chrome permissions

  • Storage saves bookmarks and preferences locally.
  • Active tab reads the page title and URL when you use the extension to capture the current page.
  • Identity supports optional Google sign-in without asking Atlas Links for your Google password.
  • Alarms schedules bounded background sync retries.
  • Side panel opens the bookmark library in Chrome's side panel.
  • Restricted Google API access allows requests only to the Google Drive and OAuth services needed for optional sync and sign-out.

Your controls

  • View, edit, export, or delete bookmarks in Atlas Links.
  • Use all local bookmark features without signing in.
  • Sign out while retaining the local bookmark collection.
  • Revoke Atlas Links' access from your Google Account permissions.
  • Clear local extension data or uninstall Atlas Links to remove its local data.
  • Use Google Drive's application-management controls to remove Atlas Links' hidden Drive application data where available.

There is no developer-held copy to request because Atlas Links has no developer-operated data server.

Security

Atlas Links validates local and remote bookmark documents before using them, communicates with Google services over HTTPS, does not load remote executable code, and avoids logging access tokens or private bookmark content. No storage or transmission method is completely risk-free, so keep Chrome and the extension up to date and protect access to your device and Google Account.

Changes to this policy

This policy will be updated if Atlas Links' data practices change. The effective date at the top of the page identifies the current version. Material changes will be reflected here before or when the related extension update is published.

Contact

For privacy questions, use a current public contact link on the publisher's GitHub profile. Do not include bookmark content, complete private URLs, access tokens, or other sensitive information in a public message.
